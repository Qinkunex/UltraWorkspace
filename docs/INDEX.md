# UltraWorkspace Documentation Center

Welcome to the **UltraWorkspace** documentation hub. Here you will find comprehensive guides on configuring your UltraBar X hardware ecosystem, binding magnetic modules, integrating smart home services, and troubleshooting issues.

---

## 📚 Quick Navigation

### 1. 📟 [Module Firmware OTA Update Guide](OTA-GUIDE.md)
Step-by-step instructions on downloading and flashing firmware (`.bin`) for QuantumLink™ magnetic modules (e.g., VivoCube) using UltraWorkspace.

### 2. 🧩 [QuantumLink™ Magnetic Modules Guide](HARDWARE-MODULES.md)
Detailed configuration manual for all hot-swappable hardware modules:
* **VivoCube**: 2.0" circular AMOLED display & multi-layer UI customization.
* **KnobKey**: Metallic rotary encoder for volume, brush size, and scrubbing.
* **DotKey**: 3-switch mechanical keypad with single/double/long press & macros.
* **SenseCube**: mmWave radar presence detection & desk-tap rhythm triggers.

### 3. 🏡 [Ecosystem & Smart Home Integrations](ECOSYSTEM-INTEGRATION.md)
Setup guides for local and cloud service bridging:
* **Home Assistant**: Controlling lights, scenes, and climate directly from CoreBAR.
* **Apple HomeKit**: Interoperability via Home Assistant bridging.
* **Sonos & Spotify**: Live album art display, volume control, and playback sync.

### 4. 🛠️ [Troubleshooting & FAQ](TROUBLESHOOTING.md)
Solutions to common questions:
* Windows directory permission issues (`C:\Program Files`).
* Power supply and USB-C PD requirements.
* CoreBAR network discovery and UDP firewall setup.
* Offline operation when PC is powered off.
